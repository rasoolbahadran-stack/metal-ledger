# مبانی تحقیق طراحی و داده بازار

این طراحی، کپی رابط هیچ سرویس تجاری نیست. ساختار کلی با مطالعه الگوهای محصولی حوزه فلزات و نرم‌افزارهای مالی شکل گرفته است؛ تمرکز این نسخه بر وضوح دفتر مشتری و مدیریت اسناد فیزیکی/مالی است، نه اجرای سفارش بورسی.

## منابع بررسی‌شده

### CME Group — Metals Futures and Options
[صفحه رسمی بازار فلزات CME](https://www.cmegroup.com/markets/metals.html) طیف فلزات گران‌بها، پایه و صنعتی را جدا می‌کند و بین محصولات/اندازه قراردادها تمایز می‌گذارد. داده‌ها و ابزارهای آن نیز تفکیک قیمت لحظه‌ای، تأخیری، پایان روز و تاریخی و مسیرهای اتصال مستقیم، REST و جریان زنده را نشان می‌دهند.

**برداشت طراحی:** فهرست محصولات و قیمت‌ها باید محصول‌محور باشد؛ زمان اعتبار، منبع و وضعیت به‌روزرسانی نرخ باید جزئی مستقل باشد. وزن و مبلغ کل چند محصول یا ارز نباید بدون برچسب و تفکیک تجمیع شوند.

### LBMA — Precious Metal Prices
[صفحه قیمت‌های معیار LBMA](https://www.lbma.org.uk/prices-and-data/lbma-precious-metal-prices) و [راهنمای مزایده روزانه](https://www.lbma.org.uk/prices-and-data/about-lbma-daily-auction-prices) برای طلا، نقره، پلاتین و پالادیوم زمان‌های متفاوت تعیین قیمت و قواعد انتشار/دسترسی داده را شرح می‌دهند. داده معیار و استفاده/بازنشر آن ممکن است مستلزم مجوز باشد.

**برداشت طراحی:** قیمت در سامانه باید شامل timestamp، منبع، ارز، واحد قیمت‌گذاری و وضعیت دستی/اتوماتیک باشد. اتصال API یا بازنشر قیمت‌های معیار بدون بررسی مجوز و شرایط استفاده نباید فعال شود.

## اصول پیاده‌شده در UI
- نمایش وضعیت محیط نمایشی و تفکیک داده نمونه از داده عملیاتی.
- اولویت اطلاعات کاربردی: مشتری، سند، نوع عملیات، محصول، وزن، مبلغ و وضعیت.
- استفاده از جدول‌های مالی راست‌چین با ستون‌های مستقل برای واحد/ارز و پیمایش افقی در صفحات کوچک.
- تفکیک دفتر وزنی از دفتر مالی؛ تحویل فیزیکی به‌صورت مستقل دیده می‌شود.
- نمایش داده بر اساس محصول و ارز؛ جلوگیری از جمع عددی ابعاد نامتجانس.
- تکیه بر نمودارهای برداری و آیکون‌های UI به‌جای عکس‌های تزئینی نامرتبط.
- طراحی تم روشن/تاریک، سایدبار واکنش‌گرا و بازخورد تعاملی کم‌تحرک.

## محدودیت تحقیق
این یک مطالعه طراحی محصول و بررسی صفحات رسمی داده/بازار است، نه ارزیابی مستقل کل نرم‌افزارهای حسابداری یا آزمون قابلیت استفاده کاربران. برای تعیین API قیمت و مجوز داده، باید بازار/کشور/منبع مورد نظر کسب‌وکار مشخص شود.
